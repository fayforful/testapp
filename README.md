[README.md](https://github.com/user-attachments/files/33325048/README.md)# PR3N7 Logs — Pastel Glassmorphism

Modern Fake Call Log Generator with beautiful pastel glassmorphism UI.

## Features
- Pastel glassmorphism design
- Phone + Contact picker
- Call Type (Incoming / Outgoing / Missed / Rejected / Blocked)
- Duration, Date & Time
- Writes real call log to device

## Build with Android Studio (Recommended)
1. Open the project folder in Android Studio
2. Sync Gradle
3. Run on device (API 26+)

## Termux note
Full Android builds in Termux need Android SDK + Gradle which is heavy.
Best experience is Android Studio on PC.

## Permissions
- WRITE_CALL_LOG
- READ_CALL_LOG  
- READ_CONTACTS
